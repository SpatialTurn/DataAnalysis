# GIS Data Analysis for Social Scientists

Source for the **Data Analysis** module of
[Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/),
published at <https://spatialturn.github.io/DataAnalysis/>.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).
Episodes live in `episodes/`; each one links to Google Colab notebooks stored in the
[DataCollection-Notebooks](https://github.com/SpatialTurn/DataCollection-Notebooks/tree/main/DataAnalysis)
repository.

| Episode file | Topic | Notebooks |
|---|---|---|
| `introduction.md` | Geocoding and adding spatial context | `01a` to `01c` |
| `networkanalysis.md` | Network analysis | `02a` to `02c` |
| `pysal.md` | Spatial autocorrelation with PySAL | `03a` to `03c` |
| `cluster.md` | Spatial clustering | `04a` to `04c` |
| `ndvi.md` | NDVI analysis | `05a` to `05c` |
